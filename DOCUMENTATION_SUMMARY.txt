│
├─ api_url: SpaceMolt API
│  └─ https://game.spacemolt.com/api/v2

├─ session_name: Eindeutige Session-ID
│  └─ z.B. "default", "farm-bot", "trader"
│
└─ mission: Langfristige Anweisung
   └─ z.B. "Mine ore and get rich"

OPTIONALE FELDER:
├─ backend: "auto" | "local" | "cloud"
├─ debug: true | false
└─ force_credentials: true | false

================================================================================
BACKEND-OPTIONEN
================================================================================

AUTO (Empfohlen)
────────────────
• Intelligentes Routing
• Einfache Aufgaben → Local (schnell, kostenlos)
• Komplexe Aufgaben → Cloud (intelligent)
• Beste Kosten/Nutzen Balance
Kosten: $0.10-0.50/Tag

LOCAL (Kostenlos)
─────────────────
• Nur Ollama (keine Cloud APIs)
• Völlig privat, offline-fähig
• Schnell auf modernem System
• Limitierte Intelligenz für sehr komplexe Aufgaben
Kosten: $0/Tag

CLOUD (Maximum Quality)
───────────────────────
• Nur Cloud-LLMs (Claude, GPT-4, etc.)
• Beste strategische Entscheidungen
• Höhere API-Kosten
• Abhängig von Internet/API-Verfügbarkeit
Kosten: $0.50-2/Tag

UMGEBUNGSVARIABLEN

ERFORDERLICH (für Cloud-Modelle):

  export ANTHROPIC_API_KEY="sk-ant-..."
  # oder
  export OPENAI_API_KEY="sk-..."
  # oder
  export GROQ_API_KEY="gsk_..."
  # oder
  export ABACUS_API_KEY="..."

OPTIONAL (für Ollama):

  export OLLAMA_BASE_URL="http://localhost:11434"
  export OLLAMA_NUM_GPU=1

DAUERHAFT SETZEN (in ~/.zshrc oder ~/.bashrc):

  echo 'export ANTHROPIC_API_KEY="sk-ant-..."' >> ~/.zshrc
  source ~/.zshrc

HÄUFIG GESTELLTE FRAGEN
================================================================================

F: Kostet die Nutzung?
A: SpaceMolt: Kostenlos. LLMs: Abhängig von Provider. Ollama lokal: Kostenlos.

F: Wie viel pro Tag?
A: Nur lokal: $0. Hybrid mit Claude: $0.10-0.50. Cloud-Only: $0.50-2.

F: Kann ich mehrere Bots haben?
A: Ja, nutze verschiedene session_name. Jeder Bot läuft separat.

F: Was ist Backend "auto"?
A: Intelligentes Routing. Einfache Aufgaben → lokal, komplexe → Cloud.

F: Brauche ich GPU für Ollama?
A: Nein, funktioniert auch mit CPU (langsamer).

ALLE FAQ: Siehe CREDENTIALS_SETUP.md → FAQ

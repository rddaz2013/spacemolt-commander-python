# SpaceMolt Commander — Setup & Installation (Linux)

> **Scope:** This guide covers installing and configuring **SpaceMolt Commander**
> on **Linux** distributions only.  All Python dependencies are installed
> with `pip` directly into the system / user Python environment — **no
> virtual environment is used**.  If you prefer a venv, follow the standard
> `python -m venv` workflow yourself; it is not required.

## 1. System Requirements

| Component | Minimum | Recommended | Notes |
|-----------|---------|-------------|-------|
| OS        | Any modern Linux (Ubuntu 22.04+, Debian 12+, Fedora 39+, Arch, etc.) | Ubuntu 24.04 LTS | Tested on `x86_64`. ARM64 works as long as Python ≥3.10 is available. |
| Python    | 3.10 | 3.11 or 3.12 | Required by `pyproject.toml`. |
| `pip`     | 21.0 | latest      | `python3 -m pip install --upgrade pip` |
| RAM       | 1 GB free | 2 GB+ | More if you also run a local Ollama model. |
| Disk      | 200 MB | 1 GB | Includes Python wheels and per-session state. |
| Network   | Outbound HTTPS to `game.spacemolt.com` **and** to your LLM provider (`routellm.abacus.ai`) | — | A corporate proxy must allow these hosts. |

You also need:

* An **Abacus RouteLLM API key** — get one from <https://abacus.ai/app/account>.
* A **SpaceMolt** account — register at <https://game.spacemolt.com> (the commander can also register a new account for you on first run).

> **Optional:** install [Ollama](https://ollama.com) if you want a free
> local LLM fallback (`ollama pull qwen3:8b`).  It is **not** required when
> you have an Abacus RouteLLM key.

## 2. Install Linux Packages

Install Python 3.10+ and `pip` using your distribution's package manager.

### Debian / Ubuntu

```bash
sudo apt update
sudo apt install -y python3 python3-pip git
```

### Fedora / RHEL / Rocky / AlmaLinux

```bash
sudo dnf install -y python3 python3-pip git
```

### Arch / Manjaro

```bash
sudo pacman -S --needed python python-pip git
```

Verify:

```bash
python3 --version          # → Python 3.10.x or newer
python3 -m pip --version   # → pip 21.x or newer
git --version
```

## 3. Clone the Repository

The project lives on the **`master`** branch.

```bash
cd ~                                           # any working directory is fine
```

## 4. Install Python Dependencies (pip, no venv)

> ⚠️ **Do not** create a virtual environment for this guide.  Dependencies
> are installed straight into your user Python with `pip install --user`.

From the repository root:

```bash
python3 -m pip install --user --upgrade pip
python3 -m pip install --user -r requirements.txt
```

Then install the project itself (editable mode is recommended so future
`git pull`s take effect without re-installing):

```bash
python3 -m pip install --user -e .
```

This installs the runtime dependencies declared in `requirements.txt` and
`pyproject.toml`:

* `litellm` — unified LLM client (Abacus / Anthropic / OpenAI / Ollama)
* `httpx` — async HTTP client for the SpaceMolt v2 API
* `click` — command-line interface
* `rich` — pretty terminal UI
* `pydantic` — typed data models
* `pyyaml` — YAML config files

After installation make sure your user-site bin directory is on `PATH`:

```bash
export PATH="$HOME/.local/bin:$PATH"            # add to ~/.bashrc / ~/.zshrc
hash -r
spacemolt --version                              # → spacemolt-commander, version 0.5.0
```

If the `spacemolt` command is missing, run it as a module instead:

```bash
python3 -m spacemolt --version
```

## 5. Initial Configuration

The commander stores **all per-user state** under:

```
~/.spacemolt/
└── sessions/
    └── default/
        ├── config.yaml      # generated by setup_config.py
        ├── credentials.json # SpaceMolt login (written after first login)
        ├── player.txt       # commander / player name
        ├── TODO.md          # autonomous agent's running TODO list
        ├── handoff.md       # last shutdown handoff summary
        ├── wiki.json        # knowledge base (auto-learned)
        └── session.log      # rotating log file (see § 7)
```

Run the interactive setup wizard:

```bash
python3 setup_config.py
```

It will ask for **only two** values:

1. **Abacus RouteLLM API key** — input is hidden; the value is written into
   `~/.spacemolt/sessions/default/config.yaml` with file mode `0600`.
   You can also pre-export `ABACUS_API_KEY` in your shell and just press
   *Enter*.
2. **Player name** — your in-game commander name (default: `Commander`).

A summary of what it writes:

```yaml
llm:
  api_key: "<your-key>"
  api_base_url: "https://routellm.abacus.ai/v1"
  model: "abacus/claude-sonnet-4-20250514"
  ...
game_api:
  base_url: "https://game.spacemolt.com/api/v2/"
  ...
player:
  name: "<your-player-name>"
session:
  default_session: "default"
logging:
  enabled: true
  level: "INFO"
  log_filename: "session.log"
  format: "%(asctime)s | %(levelname)-7s | %(name)s.%(funcName)s:%(lineno)d | %(message)s"
  ...
```

### Non-interactive (CI / scripted) setup

```bash
python3 setup_config.py \
    --non-interactive \
    --overwrite \
    --player-name "Capt. Reynolds" \
    --abacus-api-key "$ABACUS_API_KEY"
```

### Custom session location

If you want the configuration under a different directory, override the
base path:

```bash
export SPACEMOLT_HOME="/srv/spacemolt"
python3 setup_config.py
# → writes /srv/spacemolt/sessions/default/config.yaml
```

## 6. Files Created in `~/.spacemolt/sessions/default/`

| File              | Permissions | Purpose |
|-------------------|-------------|---------|
| `config.yaml`     | `0600`      | LLM + game-API + logging configuration. Contains your API key — keep private. |
| `player.txt`      | `0600`      | Plain-text player / commander name. |
| `credentials.json`| `0600`      | SpaceMolt login (username + password hash). Created by the agent after first successful login. |
| `TODO.md`         | `0644`      | Markdown TODO list maintained by the agent. |
| `handoff.md`      | `0644`      | 3–8 bullet-point summary written on graceful shutdown. |
| `wiki.json`       | `0644`      | Auto-learned knowledge base (systems, stations, recipes…). |
| `session.log`     | `0644`      | Rotating log file. See § 7. |

The setup script also `chmod`s `~/.spacemolt/` and `~/.spacemolt/sessions/`
to `0700` so other users on the machine cannot read your secrets.

## 7. Logging

A dedicated logger (`spacemolt.logger`) writes a rotating log file to:

```
~/.spacemolt/sessions/default/session.log
```

* **Rotation:** up to 5 MB per file, 3 backups (`session.log.1`, `.2`, `.3`).
* **Format** (configured in `config.yaml → logging.format`):

  ```text
  %(asctime)s | %(levelname)-7s | %(name)s.%(funcName)s:%(lineno)d | %(message)s
  ```

  Every line therefore contains:

  | Field | Example | Source |
  |-------|---------|--------|
  | Timestamp | `2026-05-17 14:32:11` | `%(asctime)s` (`logging.Formatter`) |
  | Level | `INFO   ` | `%(levelname)-7s` |
  | Module + function | `spacemolt.api.execute` | `%(name)s.%(funcName)s` |
  | Line | `:107` | `%(lineno)d` |
  | Message | `execute — command=spacemolt/mine args=...` | `%(message)s` |

* **Level:** controlled by `config.yaml → logging.level` (`DEBUG` /
  `INFO` / `WARNING` / `ERROR`).  Override at runtime with `--debug`,
  which forces `DEBUG`.
* **Console:** the rich-coloured terminal output (`spacemolt.ui`) is
  independent of the file logger; both are active in parallel.

Tail the log live:

```bash
tail -f ~/.spacemolt/sessions/default/session.log
```

Disable file logging (per-session) by setting `logging.enabled: false` in
`config.yaml`.

## 8. Basic Usage

### Run a single mission

```bash
spacemolt run "Mine ore and maximise profit"
```

…or, if the `spacemolt` console script is not on your `PATH`:

```bash
python3 -m spacemolt run "Mine ore and maximise profit"
```

### Continuous service mode

```bash
spacemolt service --mission "Dominate the galaxy"
```

### Check session status

```bash
spacemolt status --session default
```

### Force a specific backend

```bash
spacemolt run "Quick status check" --backend local
spacemolt run "Plan a 5-system trade route" --backend cloud
```

### Use a non-default session

```bash
spacemolt run "Mining run"  --session miner_bot
spacemolt run "Trade route" --session trader_bot
```

Each session has its own directory under `~/.spacemolt/sessions/<name>/`
with its own `config.yaml`, credentials, TODO list and `session.log`.

## 10. Troubleshooting

### `command not found: spacemolt`

The console script lives in your user `~/.local/bin/`.  Add it to `PATH`:

```bash
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
```

Or invoke as a module:

```bash
python3 -m spacemolt --version
```

### `ModuleNotFoundError: No module named 'spacemolt'`

You ran `python3 setup_config.py` or `python3 -m spacemolt` from outside
the repository **and** did not install the package.  Either:

* `cd` into the cloned repo first, **or**
* install in editable mode: `python3 -m pip install --user -e .`

### `Permission denied` writing to `~/.spacemolt/`

Most likely the directory was created by `sudo` previously.  Fix ownership:

```bash
sudo chown -R "$USER:$USER" ~/.spacemolt
chmod 700 ~/.spacemolt ~/.spacemolt/sessions
```

### `httpx.ConnectError` / network failures

Make sure outbound HTTPS to **both** of these hosts is allowed:

* `https://game.spacemolt.com/api/v2/` — the only Game API endpoint used.
  The legacy `https://game.spacemolt.com/api/v1/` is **not** referenced
  anywhere in the code base.
* `https://routellm.abacus.ai/v1` — Abacus RouteLLM API.

Test manually:

```bash
curl -I https://game.spacemolt.com/api/v2/
curl -I https://routellm.abacus.ai/v1
```

If you are behind a corporate proxy, export it before running:

```bash
export HTTPS_PROXY=http://proxy.example.com:3128
export HTTP_PROXY=$HTTPS_PROXY
```

### `Invalid API key` from Abacus RouteLLM

* Re-check the key in `~/.spacemolt/sessions/default/config.yaml` (or
  `$ABACUS_API_KEY` if you exported it).
* Re-run `python3 setup_config.py --overwrite` to enter a fresh key.

### Session log is empty

* Confirm `logging.enabled: true` in `config.yaml`.
* Confirm write permissions on the session directory:
  `ls -la ~/.spacemolt/sessions/default/`.
* Run with `--debug` to force `DEBUG`-level output.

### Old `./sessions/<name>/` directory in the repo

Earlier versions of the project stored state in `./sessions/` relative to
the working directory.  For backward compatibility the `SessionStore`
keeps using that location **if it already exists**.  Move it to the new
default with:

```bash
mkdir -p ~/.spacemolt/sessions
mv ./sessions/default ~/.spacemolt/sessions/default
```

### Reset everything

```bash
rm -rf ~/.spacemolt/sessions/default
python3 setup_config.py
```
